# 课堂译记 · 公开版

多语言课堂实时转写、中文翻译、PPTX/PDF/DOCX/TXT/Markdown 参考资料、课后总结与 PDF/HTML/Markdown 导出。

支持登录会员和个人 API Key 两种连接方式。首次短信验证成功后注册账户，后续使用同一手机号登录。会员共享 API Key 只保存在服务器环境中，个人 API Key 只在当前页面内存中保存。同源服务只转发到固定的 OpenAI 接口。实时音频使用临时凭据直接连接 OpenAI。未登录的课堂和资料保留在当前浏览器 IndexedDB；登录后按账户保存到云端，并保留本地副本。

录音控制栏可选择自动识别或常用语言 → 中文。新课堂默认自动识别，旧课堂保留英语设置。开始前或暂停时可切换；继续录音等待服务确认新语言后再采集。语言随课堂保存，每段保留录入时的语言设置，试译与导出也使用该设置。

资料读取文字层，图片、扫描件和图表不做视觉识别。每份 20 MB、每课 10 份。旧 PPT/DOC 需转换格式。

开发：`npm ci`、`npm run build`、`npm test`。测试使用模拟响应，不消耗 OpenAI 额度；实际账户权限、余额及麦克风环境需要使用者连接验证。

部署输出为 Cloudflare-compatible Worker：`dist/server/index.js`，内嵌浏览器静态资源。D1 保存账户、会话摘要、会员等级和到期时间、兑换记录、短信挑战、用量计数及账户历史索引；R2 保存账户课堂内容和提取的资料文字。不保存密码明文或 API Key。

服务器秘密配置：`MEMBER_CODE` 和 `OPENAI_API_KEY`。账户会话使用随机 256 位令牌，数据库仅保存 SHA-256 摘要；Cookie 为 HttpOnly、Secure、SameSite=Strict，30 天过期，退出后服务器立即撤销。旧匿名会员 Cookie 不再授予共享权限。`MEMBER_SESSION_SECRET` 为旧配置，当前账户会话不依赖它。

会员兑换必须登录。一个账户对同一会员码仅领取一次，从首次领取开始精确计时 7 天；重试不延长，过期后同一码不可再次领取。兑换不降低仍有效的高级会员等级。数据库支持 `none`、`regular`、`premium`，所有有效会员均须有到期时间；到期后的有效身份为非会员。高级会员暂未提供购买或自行升级入口。共享 API 每次请求都验证账户及会员有效期；未配置共享 Key 时明确提示不可使用。修改会员码不会撤销已领取权益，新码可以作为新的领取活动。

共享服务默认限制：每个账户每 10 分钟最多 15 次兑换尝试、每分钟 60 次文字请求和 3 次实时连接申请。所有会员合计每天最多 3000 次文字请求、12 次实时连接凭据、500 万输入字符；按 UTC 日重置。管理员可用 `MEMBER_DAILY_TEXT_LIMIT`、`MEMBER_DAILY_REALTIME_LIMIT`、`MEMBER_DAILY_CHARACTER_LIMIT` 调整。数据库原子计数，限制失败不调用共享 API。这些是请求上限，并非精确金额上限。已经发出的短期音频凭据由 OpenAI 管理，本站不能撤销已经建立的音频连接；后续文字翻译和总结仍检查会员到期状态。

数据库结构在 `db/schema.ts`，执行 `npx drizzle-kit generate` 生成迁移。发布时应用已保存的 `drizzle` 迁移。测试包含真实 SQLite 计数和模拟 OpenAI 调用，无真实费用。

## 个人中心

个人中心未登录时显示「未登录」。手机号支持中国大陆 11 位号码自动加 `+86`，其他国家输入完整国际区号。首次验证码通过才写入账号与手机号，页面只返回脱敏号码。邮箱、微信继续保留待接入状态。

短信提供方尚未配置时，发送和登录按钮禁用，后台返回 503，不创建假账号、不接受测试验证码。已预留 Twilio Verify 适配器；管理员可接入该服务，或替换 `src/phone-server.js` 中的提供方适配。启用需要在服务器秘密设置中配置 `SMS_PROVIDER=twilio-verify`、`TWILIO_ACCOUNT_SID`、`TWILIO_AUTH_TOKEN`、`TWILIO_VERIFY_SERVICE_SID`，并完成服务方对应国家的短信开通与投递配置。密钥不能放入前端或提交 Git。

接口：`POST /api/account/phone/send` 接收 `phone`，返回随机挑战 ID；`POST /api/account/login/phone` 接收 `challengeId` 与 `code`。验证码由服务方发送和验证，本站不存储验证码。挑战有效 10 分钟，最多验证 5 次，一次验证只签发一次会话。发送限制为每手机号每分钟 1 次、每天 10 次，每网络地址每 10 分钟 5 次，站点每天合计 100 次；验证每网络地址每 10 分钟 20 次。错误响应不暴露提供方密钥。未完成挑战在过期后、下一次发送时清理。

`GET /api/account` 返回账号、有效会员等级及到期时间；`POST /api/member/login` 兑换会员码；`POST /api/account/logout` 退出。客户端传入的等级、到期时间或身份不能授权。所有课堂和资料读写校验归属。账号浏览器副本分开保存；保存云端失败保留本地副本并提示，并发修改有版本检查。不会将未登录的浏览器记录自动归入新登录账户。

测试使用独立内存数据库与模拟短信提供方，覆盖注册、重复登录、会话退出、验证失败与重放、频控、会员兑换与到期、API 权限和历史隔离。不发送真实短信、不消耗 OpenAI 额度。真实短信投递及共享 API 仍需配置后验收。

适配器接口依据：[Twilio Verification](https://www.twilio.com/docs/verify/api/verification) 与 [Verification Check](https://www.twilio.com/docs/verify/api/verification-check)。

## 笔记下载

“下载 PDF”直接生成 A4 PDF，总结后自动下载也使用 PDF。中文字体随网站提供并嵌入导出文件；常见中英文文字可选择和复制，字体未覆盖的字符在浏览器中绘制保留。长笔记自动分页，包含总结、参考资料、记录提示和双语记录。生成在浏览器内完成，不将笔记发送给额外服务，不调用 API。原 HTML/Markdown 导出保留明确格式标签；文件名会清理不兼容字符。下载后的默认打开软件由操作系统决定，网站不自动启动外部应用。

PDF 字体：Android 开源项目 Droid Sans Fallback（Apache 2.0）；原始许可见 `public/export-font-LICENSE.txt`，来源为 Android `platform/frameworks/base` 的 `android10-release/data/fonts/DroidSansFallback.ttf`。

## 本机麦克风

录音优先选择具名的电脑内置麦克风，并用精确设备 ID 锁定，不跟随系统的默认输入设备。电脑端排除 iPhone、连续互通和常见虚拟输入；无内置麦克风时可使用识别到的本地 USB／耳机麦克风。未找到本地输入或指定设备失效时提示重试，不自动回退手机。录音状态显示实际设备名称，设备断开后暂停，继续录音会重新选择本地输入。

浏览器首次授权前可能隐藏设备名称，此时必须先申请麦克风权限。临时权限流立即静音并关闭，不连接转写服务；获得设备名称后再打开本机设备。此首次授权步骤仍受浏览器及系统默认输入设置影响。已经授权且可以识别本机设备时直接打开该设备，不申请默认输入。手机上访问本站时允许使用手机自己的内置麦克风。设备排序、精确指定、权限流清理和禁止回退均使用模拟设备测试；未调用真实转写 API。

## 专业与术语

个人中心提供常见专业选择及最多 60 字的自定义专业名称。偏好自动恢复，按当前账户／访客分开保存在本机独立的 IndexedDB，不要求登录，也不修改原课堂数据库。当前登录提供方仍待接入；专业偏好本身不承诺跨设备同步。

新课堂、继续录音、试译和重新总结会读取当前保存的专业；进行中的课堂使用开始时的专业快照。专业随课堂记录保存，已有译文和笔记不自动重写。翻译请求同时带上专业背景、参考资料和最近已译内容，要求领域通行译名、同一概念一致、必要时保留原文，并禁止按专业强行改写口述。长课堂的分段总结和最终总结也传入专业背景。自定义名称只作为不可信输入数据传入，不拼入系统指令。模拟测试确认偏好隔离、历史保留及实际请求中的专业／术语约束；真实术语准确率仍取决于课堂音质、语境和模型输出。
